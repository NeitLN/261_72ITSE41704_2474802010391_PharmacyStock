## How these reports are written

- **Dates are kept apart.** Each report states when the work happened, when
  the evidence was created, and when the report was written. Reports for
  weeks 1–4 were written on **12/10/2026** from the evidence that exists; they
  say so at the top and do not backdate anything.
- **Evidence first.** Every "delivered" item links to a commit, pull request,
  issue, test run or receipt. Work that has no evidence in the repository is
  listed as such, even if it happened.
- **Statuses.** *Accepted* = merged after review and test-run by someone other
  than the author. *Awaiting review* = finished by its author, in an open pull
  request. *Not delivered* = planned for the week and not finished.
- **Contribution numbers** are counts from Git and GitHub (commits, pull
  requests opened, reviews given) for that week. They show activity, not
  value; the narrative says what each piece of work was.
- From week 5 the report is updated during the week and closed on Sunday,
  after the Wednesday contribution check recorded in the journal.
